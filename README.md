# mil-t

A learning project following along with [kilo](https://viewsourcecode.org/snaptoken/kilo/) — a small terminal text editor written in C.

The goal is to understand how terminals work at a low level (raw mode, escape sequences, etc.) and then build on top of it by adding my own features in the future.

## Build

```bash
make
```

## Run

```bash
./mil-t
```

Press `q` to quit.
